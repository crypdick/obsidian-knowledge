# Note types

Classify by content, respecting local layout:

| Type | Subfolder | Content |
| --- | --- | --- |
| Background reference | `reference/` | Editable lookup notes, not protected `_sources/` originals |
| Design or plan | `plans/` | Decisions, implementation plans, roadmaps |
| Conversation | `convos/` | Comparisons, rationale, research synthesis |
| Diary | `diary/` | Incidents, events, or processes |
| Wiki, guide, or TODO | Folder root | Compiled knowledge, how-tos, backlogs |

`DUMPING_GROUND` flags folders with at least four inline date-prefixed,
`-design.md`, `-convo.md`, or `-diary.md` files. Treat it as a review signal,
not an instruction to move every match. Move misplaced notes through Obsidian;
index new subfolders and link them from the parent. See
[index and move conventions](index-format.md).
